# Lazada Commerce / Product-Discovery Evidence Ledger

Source identifiers for `../../platforms/commerce/lazada.md`.

Lazada Open Platform documentation has endpoint-specific freshness: several product/category pages were last updated in 2024, while product-creation guidance and adjacent developer docs were updated in 2025. Treat these as the currently available integration contracts for the cited APIs, not as proof that every production commerce/search system is unchanged. Reviewed 2026-08-23.

## [LZ01] Lazada Open Platform — Product API / item and SKU identity

Lazada Open Platform. **Product API Overview; Product API; GetProducts / product information.** Current available docs reviewed 2026-08-23; key product pages last updated July 19, 2024.

Use: product-management APIs distinguish item/product records from SKUs. `item_id` is generated by Lazada and described as unique in the current country; one item can have multiple SKU IDs. `SellerSku` is seller-customizable and unique in the store; `SkuId` is created by Lazada. Product/SKU status can be active, inactive or deleted.

Boundary: Lazada API nouns/IDs are scoped implementation identities, not universal product ontology.

## [LZ02] Lazada Open Platform — categories and item/SKU attributes

Lazada Open Platform. **GetCategoryTree; GetCategoryAttributes; product-management guide.** Current available docs reviewed 2026-08-23; core attribute pages last updated July 19, 2024.

Use: category trees/IDs can differ by country. `attribute_type=normal` denotes item/SPU-level attributes; `attribute_type=sku` denotes SKU-level attributes. `is_sale_prop` marks variant/sales attributes. `is_key_prop` marks key attributes; docs say filling them can improve a product/item score/rating.

Critical boundary: the documented product/item score is not established as an organic Search ranking score. Do not translate `is_key_prop` into a ranking-weight claim.

## [LZ03] Lazada Open Platform — Create Product, category suggestion, brands, images, and seller input

Lazada Open Platform. **Create Product / what to do before creating a product.** Current page available and reviewed 2026-08-23; page crawled from a 2025-updated contract.

Use: sellers/developers should retrieve country-specific category trees, use category suggestion from product title, retrieve category attributes, use country-specific brand libraries, migrate/upload images, and submit product attributes plus one or more SKUs. Mis-categorized products can be deactivated.

The current API contract also exposes algorithmic assistance / auto-fill options in product creation where supported; use such platform-filled state as derived platform data with provenance rather than seller-declared truth.

Boundary: category suggestion, key fields, auto-fill, and listing requirements do not reveal organic retrieval/ranking weights.

## [LZ04] Lazada Open Platform — price and inventory state

Lazada Open Platform. **Product-management / GetProducts / SKU inventory APIs.** Reviewed 2026-08-23.

Use: SKU-level data includes price / special-price validity where supported, quantity, seller SKU / platform SKU, and warehouse-scoped inventory. Inventory can distinguish sellable quantity, withhold quantity for unpaid purchases, occupy quantity for paid purchases, and total quantity; multi-warehouse inventories can be exposed.

Supports:

SELLABLE

Boundary: integration inventory state does not establish every buyer-facing availability promise or logistics estimate.

## [LZ05] Lazada Open Platform — global product / ventures and country scope

Lazada Open Platform. **Global Product / ventures documentation; cross-border authorization.** Current available docs reviewed 2026-08-23.

Use: global/cross-border product-management objects can target ventures including MY, SG, TH, PH, ID and VN; category trees, category IDs and brand libraries can differ by country. Cross-border seller authorization can span six ventures.

Boundary: a `global_product` or SPU/global-management object is a Lazada cross-market management identity, not a universal industry product entity. Local country item/SKU/commercial state can differ.

## [LZ06] Hongwimol et al. — AutoPKG at Lazada

Hongwimol, P., Shang, H., Wang, C., Wan, Z., Gao, Y., Li, Y., Gui, L., Sun, W., & Yu, C. (2026). **AutoPKG: An Automated Framework for Dynamic E-commerce Product-Attribute Knowledge Graph Construction.** arXiv:2604.16950.

Use: Lazada/Alibaba engineering evidence that multimodal product content can be used to induce product types and attribute keys, extract values, and canonicalize them into a product-attribute knowledge graph. Online A/B tests reported GMV improvements for AutoPKG-derived attributes in Badge (3.81%), Search (5.32%), and Recommendation (7.89%) in the tested production applications.

Boundary: the experiment supports the tested AutoPKG-derived attribute system. It does not show that manually filling arbitrary seller fields yields the same effect, nor does it disclose exact organic ranking weights.

## [LZ07] Lazada — Search / Recommendation / Advertising system existence

Lazada Careers. **Technology, AI & Product.** Reviewed 2026-08-23.

Use: Lazada publicly states that its AI organization works on search, recommendation, and advertising algorithms, and that Product covers search/recommendations, social, advertising/marketing and adjacent marketplace experiences.

Boundary: corporate description establishes system families, not production architecture, features, weights, or objectives.

## [LZ08] Lazada Sponsored Solutions — sponsored ranking / placements / 2026 migration

Lazada Sponsored Solutions. **What determines my promoted products' ranking?; Where will Sponsored Discovery promoted products appear?; Sponsored Discovery Is Being Phased Out – August 2026; Sponsored Max FAQs.** Reviewed 2026-08-23.

Direct migration announcements:

- Global announcement, published 2026-08-20: `https://www.lazadasolutions.com/news-updates/sponsored-discovery-auto-upgrade/`
- Vietnam-local announcement, published 2026-08-18: `https://www.lazadasolutions.com/vn/vn-news-updates/vn-sponsored-discovery-auto-upgrade/`

Use: Sponsored Discovery product ranking disclosures name bid competitiveness, keyword selection, and promoted-product quality examples such as historical sales, ratings, positive reviews and creatives. Sponsored placements include Search Results and recommendation surfaces such as Homepage For You and PDP Recommendations. Lazada announced that starting September 19, 2026 it will phase out selected Sponsored Discovery automated/product campaign types, upgrading eligible campaigns to Sponsored Max Store/Product between September 19–30; Manual remains unchanged in the announced global plan. Sponsored Max currently promotes through Search and Recommendations.

Boundary: this is **paid advertising system evidence**. Never transfer sponsored ranking factors, placements, or optimization advice to organic Search/Recommendation. The announced migration also demonstrates that even official product documentation is time-sensitive. Local naming/rollout wording can differ by market, so use the market-specific announcement when executing locally.
