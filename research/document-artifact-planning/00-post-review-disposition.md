## Smallest surviving gap

The independent review reduced the candidate to two adjacent weaknesses inside the existing planning/presentation owner.

### 1. Use / retrieval contract

The current report contract already handles reader purpose, section function, evidence, representation, and delivery, but its dominant shape remains report-centric.

A document-like marketing artifact can instead require:

```text
linear comprehension
skimming
selective lookup
comparison
repeated reference
work-through
```

These are conditional use modes, not a new taxonomy or ontology. Preserve only those that materially change architecture.

Navigation follows use, not document length alone. A short reusable reference can need stable labels, modular units, local context, or cross-reference even when it is not long enough to resemble a traditional report.

### 2. Conditional work-through continuity

A reader-facing workbook/action artifact may require:

```text
required input
→ activity / decision / transformation
→ recorded output
→ carried-forward state
→ checkpoint / next dependency
```

This is not a generic workflow primitive or state machine. It is a conditional document-planning procedure used only when the reader must perform work through the artifact.

Without it, a system can produce a factually correct and visually polished pseudo-workbook consisting of guide prose, questions, and blank boxes whose outputs do not support later activities.

## Authorized implementation

The bounded repair may:

1. generalize controller activation from complex reports/syntheses to document-like marketing artifacts when structure, representation, retrieval, or working-use architecture remains materially open;
2. generalize the existing report contract toward an artifact/use contract while preserving the same owner;
3. add explicit retrieval/use-mode guidance only when it changes architecture;
4. add the conditional reader work-through chain;
5. extend representation examples with checklist, decision aid, worksheet, and exercise only when they perform a real information or action job;
6. add targeted regression cases protecting the direct path and owner boundaries.

The repair must preserve:

```text
ARTIFACT NOUN != ACTIVATION AUTHORITY
PDF != CAPABILITY BOUNDARY
DOMAIN != LAYOUT ORACLE
VISUAL != DECORATION
WORKBOOK != PROSE + BLANK BOXES
BRAND IDENTITY != DOCUMENT APPLICATION ARCHITECTURE
DOCUMENT PLANNING != GENERIC GRAPHIC DESIGN
```

## Reopen condition

Reconsider a dedicated specialist only if realistic recurring failures survive:

```text
controller activation repair
+
existing-owner generalization
+
Chapter 04 / Chapter 11 / Chapter 15 handoffs
+
ordinary design/production execution
```

and still demonstrate an irreducible document-level decision that the existing planning/presentation owner cannot represent without material ambiguity or loss.

Professional usefulness, client demand, document length, PDF delivery, visual complexity, or the existence of named document genres do not satisfy that gate.
