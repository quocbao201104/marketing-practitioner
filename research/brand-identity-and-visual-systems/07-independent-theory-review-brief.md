## 3. Frozen candidate claims under review

The review target asserts, provisionally, that:

1. a decision-relevant visual-identity gap exists;
2. the smallest plausible owner is visual-identity realization/stewardship downstream of sufficiently resolved brand/market strategy;
3. the owner should not create a new controller job or durable primitive;
4. identity tasks should start from the open decision and preserve resolved upstream state;
5. redesign must preserve possible learned equity rather than assume reset;
6. intended meaning and observed perceptual reading are distinct;
7. visual properties are context-dependent variables, not universal quality rules;
8. candidate distinctiveness potential is not learned distinctive-asset strength and neither is legal clearance;
9. exploration and controlled refinement are distinct modes;
10. deployment testing is decision-relevant only for environments that can change the choice;
11. generative output is exploration evidence, not automatically a production master;
12. country/language mention does not automatically justify identity redesign;
13. the theory should be JIT-addressable rather than a mandatory branding funnel.

The reviewer should attack every one of these claims.

## 4. Primary adversarial tests

### A. Gap necessity

Construct at least three realistic tasks where the current repository appears to fail without the proposed owner.

For each, attempt the strongest existing-owner resolution first.

Use this form:

```text
INPUT / TASK
→ EXISTING OWNER(S)
→ BEST CURRENT RESOLUTION
→ REMAINING FAILURE, IF ANY
→ DOES THAT FAILURE CHANGE THE DECISION?
```

A gap survives only if the remaining failure is material.

If Chapter 03, Chapter 04, Chapter 07, Chapter 11, general source-fidelity rules, or ordinary model capability can already solve the task without material distortion, count that against the proposed owner.

### B. Owner-boundary attack

Try to make the candidate owner absorb decisions that belong elsewhere.

At minimum test:

```text
brand positioning still unresolved
copy/message unresolved
country-specific symbolism concern
landing-page visual placement
product UI icon system
naming conflict
packaging/art direction
trademark registrability
```

For each case, determine whether the proposed theory preserves the existing owner or becomes a new catch-all `brand` layer.

### C. Folklore attack

Identify every runtime-shaped claim that could merely be:

- studio convention;
- aesthetic preference;
- anecdotal case-study practice;
- one-brand design-system rule;
- popular branding folklore;
- a model-generated synthesis without sufficient evidence.

Particularly attack:

```text
concept territories
form families
controlled micro-variants
misread testing
small-size testing
system commit
preserve/evolve/replace
```

The question is not whether these are sensible. The question is whether they are sufficiently supported and bounded to govern an agent.

### D. False-universal attack

Try to generate counterexamples to every apparent rule.

Examples:

- a complex mark that is highly effective;
- a literal/descriptive mark that is strategically useful;
- an abstract mark that is generic;
- a deliberate ambiguous mark;
- a mark whose asymmetry is essential;
- a brand whose tiny-size icon is a separate asset rather than a reduced logo;
- a rebrand where replacement is justified despite existing awareness;
- a market adaptation where visual change really is necessary.

The theory passes only if these cases remain representable without contradiction.

### E. State-preservation attack

Test whether the candidate really obeys the repository's resolved-state invariant.

Examples:

```text
"Just fix the aperture."
"Only make a favicon from this approved mark."
"Keep the logo; choose dark-mode treatment."
"The positioning is approved; create 3 visual directions."
```

The theory should not reopen more state than the current decision requires.

### F. Equity/redesign attack

Try to falsify `REDESIGN != RESET` as an operating rule.

Test at least:

- strong measured asset linkage;
- long usage but no measured linkage;
- weak/new brand with low awareness;
- materially harmful existing symbolism;
- merger/acquisition with changed brand architecture;
- technical deployment failure that the current mark cannot survive.

Check whether `preserve / evolve / replace` is a useful bounded decision or merely a generic design-review label.

### G. Distinctiveness semantics attack

The candidate separates:

```text
visual distinctiveness potential
learned distinctive-asset strength
legal distinctiveness / clearance
```

Try to construct cases where these categories collapse, conflict, or become misleading.

Check especially whether the theory improperly imports Ehrenberg-Bass terminology as a universal evaluation framework rather than one evidence line.

### H. Generative-AI attack

Determine whether controlled refinement is actually a marketing-theory requirement or merely a workaround for current image-model drift.

Ask:

- would the method remain valid with perfect deterministic vector editing?
- which part is durable decision theory versus tool-specific operational discipline?
- should any AI-generation guidance live in runtime marketing knowledge at all?

If a rule exists only because today's image models are unstable, flag it as implementation/tool guidance rather than durable marketing theory.

### I. Legal-boundary attack

Check that legal pre-flight remains an external dependency rather than a pseudo-legal subsystem.

Attempt cases involving:

- exact duplicate found;
- similar figurative mark in another class;
- similar mark in another jurisdiction;
- descriptive/simple geometric mark;
- no search result;
- unlicensed typeface or stock element;
- generated image with unclear provenance.

The theory must not overclaim clearance or ownership.

### J. Localization attack

Test whether Chapter 07 remains owner of local realization.

Try:

- a harmless country mention;
- non-Latin wordmark/script requirements;
- local symbol with materially different meaning;
- regulatory or accessibility constraint;
- multinational brand that intentionally preserves one global mark.

The candidate should activate localization only when local evidence can change the identity decision.

### K. JIT/composition attack

Determine whether the proposed decision areas can be loaded independently or whether they secretly require a linear branding curriculum.

Try narrow tasks that should need only:

```text
refinement
perceptual test
deployment test
equity adjudication
legal pre-flight
system commit
```

If the theory cannot answer them without reconstructing the entire brief/audit/territory stack, mark the JIT claim as failed.

The reviewer must explicitly adjudicate at least these cases:

1. User supplies approved logo and asks for a favicon.
2. User supplies six generated logos and asks which are likely to be misread.

11. Landing-page designer asks where to place the logo and proof row.
12. Product designer asks for a complete UI component design system.
13. A generated raster candidate looks good but exact curves change on every edit.
14. A long-used color has strong buyer linkage but a new designer dislikes it.
15. A descriptive logo performs well in recognition tests but has weak legal distinctiveness.

Use additional cases if needed, but do not broaden merely for completeness.

## 6. Evidence discipline

Distinguish at least four evidence classes:

```text
EMPIRICAL / ACADEMIC EVIDENCE
OFFICIAL LEGAL / STANDARD SOURCE
PROFESSIONAL PRACTICE EVIDENCE
PROJECT SYNTHESIS / HYPOTHESIS
```

Do not promote a studio case study into a universal causal law.

Do not treat one company's identity guideline as a general standard.

Do not infer a consumer/business outcome from a visual property unless the evidence actually supports that scope.

Do not reject a useful practitioner synthesis merely because it is not academically novel; instead require that its parent concepts and limits are explicit.

## 9. Permitted verdicts

Return exactly one of:

```text
THEORY_PASS
THEORY_PASS_WITH_LOCAL_REPAIRS
THEORY_REQUIRES_REDESIGN
THEORY_GAP_NOT_JUSTIFIED
```

### `THEORY_PASS`

Use only if the gap, owner, boundaries, invariants, and JIT model survive without material correction.

### `THEORY_PASS_WITH_LOCAL_REPAIRS`

Use when the core owner survives but a bounded number of local theory defects must be repaired before runtime promotion.

Repairs must not require a new owner, new primitive, or broad reconceptualization.

### `THEORY_REQUIRES_REDESIGN`

Use when a meaningful visual-identity gap exists but the proposed decomposition/boundaries are materially wrong, over-broad, under-specified, or dependent on folklore/tool behavior.

### `THEORY_GAP_NOT_JUSTIFIED`

Use when the supposed gap can already be handled adequately by existing owners/invariants/model capability, or when the proposed capability would mainly expand Marketing Practitioner into general design practice without a distinct marketing decision owner.
